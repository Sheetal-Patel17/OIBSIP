🚀 Completed Task 1 of my Data Science Internship with Oasis Infobyte!

I’m excited to share my first project: **Iris Flower Classification**.

For this task, I built a complete machine-learning classification workflow using Python and scikit-learn. The project includes:

• Exploratory Data Analysis (EDA)
• Pairplot and feature-wise box plots
• Feature-selection/discriminative-feature analysis
• 80/20 stratified train-test split
• Logistic Regression and Random Forest classifiers
• Accuracy, precision, recall, and F1-score evaluation
• Confusion matrices and model comparison
• Random Forest feature-importance analysis

On the executed test split (`random_state=42`):
**Logistic Regression — 93.33% accuracy**
**Random Forest — 90.00% accuracy**

The analysis also showed that petal length and petal width were the most important features in the Random Forest feature-importance analysis for this run.

This project helped me strengthen my understanding of the end-to-end machine-learning workflow, from data exploration and visualisation to model evaluation and interpretation.
