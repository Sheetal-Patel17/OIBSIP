# Demo Video Script — Oasis Infobyte Task 1

## Required opening title card (first 2 seconds)
**Sheetal Patel**
**Data Science**
**Task 1 — Iris Flower Classification**

## Suggested walkthrough
1. Show the title card for 2 seconds.
2. Introduce the objective: classify Iris Setosa, Versicolor, and Virginica from four measurements.
3. Show the built-in scikit-learn dataset and point out the shape, data types, null check, and descriptive statistics.
4. Show the pairplot and explain that petal measurements separate the species more clearly than some sepal measurements.
5. Show the box plots for all four features.
6. Explain the 80/20 stratified train-test split.
7. Show the two trained classifiers: Logistic Regression and Random Forest.
8. Show accuracy, precision, recall, F1-score, classification reports, and both confusion matrices.
9. Show the model comparison and explain the selection rule: higher test accuracy, with macro F1 as the tie-breaker.
10. Show Random Forest feature importance and explain which features are most important in this run.
11. End with the conclusion and repository structure.

## Speaking reminder
Explain what each section means in your own words. Do not read a tutorial word-for-word.
